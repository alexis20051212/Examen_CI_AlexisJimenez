# Examen CI - Alexis Jiménez Salas

## Proyecto
**Sistema de Cálculo de Descuentos**

## Objetivo
Desarrollar un sistema sencillo que calcule el precio final de un producto aplicando un porcentaje de descuento, gestionando su código con control de versiones (Git) y validando cada cambio mediante un flujo de integración continua (CI) con pruebas automatizadas, para detectar y corregir errores antes de que lleguen a producción.
